# Masta-Octa UI internationalization (i18n)

## Approach

The desktop app uses a **TypeScript message catalog** with a typed `t(key, vars?)` helper and
`LocaleProvider`. We deliberately **do not** add i18next or other runtime i18n npm packages:
messages are static objects, parity is enforced in tests and typecheck, and the bundle stays
small.

Persistence follows the same pattern as themes: `localStorage` key `masterocta.ui-locale`,
best-effort writes, default **`ja`** when missing or invalid. `main.tsx` calls
`applyStoredLocaleBeforePaint()` before the first paint and sets `document.documentElement.lang`.
Language changes use `startTransition` and **do not** call `location.reload()`.

## Adding strings

1. Add the key and English copy to `src/i18n/messages/en.ts`.
2. Add the **same key** and Japanese copy to `src/i18n/messages/ja.ts` (`satisfies Record<MessageKey, string>`).
3. If the string uses `{placeholders}`, extend `MessageParams` in `src/i18n/messages/index.ts`.
4. Use `useTranslate()` in components: `t('your.key', { count: 1 })`.
5. Prefer **full sentences** per key; do not concatenate translated fragments in the UI.
6. Never use translated labels as React keys, API values, or internal state identifiers.
7. User-visible file names and Octatrack paths stay literal; only chrome is translated.
8. Do **not** use `dangerouslySetInnerHTML` for translated text.

Unknown keys fall back to English at runtime (with the key name kept for diagnosis).

## Errors

Backend / IPC `Error.message` strings stay as returned. Map known validation cases to stable
**codes** (for example waveform range empty / beyond file / preview limit) and translate via
`t()` in the UI. Unknown errors show a generic message plus diagnostic detail in a separate node.

## Tests

- `src/i18n/messages.test.ts` — ja/en key and placeholder parity.
- Component tests: import `tJa` / `tEn` from `src/i18n/testStrings.ts` for labels and aria text.
- E2E: `e2e/i18n.ts` `uiText(locale, key, vars?)` so locators track the catalog (default UI locale is ja).

## Scope (MO-UI-I18N-LIBRARY-1)

**Translated in this wave:** AppShell context bar, Sources, Library browse (catalog browser,
AudioLibrary, ProjectWorkspace), Inspector shell, manual tags/notes, Waveform preview (loading,
errors, range playback UI), legacy write restriction notice, span duration labels.

**Not translated yet:** Clone / Rename / Change Drawer operator copy, Slice workbench, Usage Graph
row formatting, Home legacy Scan/Browse/project search, legacy ProjectDetail / Audio Pool / Tools,
Docusaurus user-guide.

## Waveform / locale

Changing locale must **not** re-run waveform IPC. `WaveformPreview` query effects depend on
`[api, assetId, rootId, debouncedTargetPoints, debouncedViewport]` (plot width + zoom/pan
viewport), not on `t` or locale. Locale changes must **not** reset viewport, selection, or
playback state.

Waveform zoom/pan/drag strings live under `waveform.zoom*`, `waveform.pan*`,
`waveform.fitSelection`, `waveform.interactionHint`, and `waveform.viewportFrames`.
